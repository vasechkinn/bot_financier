Асинхронный Telegram-бот для учёта личных доходов и расходов, постановки финансовых целей и отслеживания прогресса.  
Написан на Python с использованием `aiogram 3`, `SQLAlchemy` (асинхронный) и `SQLite`.

Функционал:
- 📝 Регистрация пользователей (логин/пароль) через FSM
- ➕ Добавление доходов (`/add_income`)
- ➖ Добавление расходов (`/add_expense`)
- 📊 Просмотр истории операций с фильтрацией по периоду (день/неделя/месяц/год) и категории
- 🎯 Установка финансовых целей (`/set_goal`) и отслеживание прогресса (`/goals`)
- 🔐 Защита команд: только авторизованные пользователи имеют доступ (middleware)
- 💾 Автоматическое создание базы данных и таблиц через SQLAlchemy

Технологии:
- `aiogram` 3.
- `aiosqlite` + `SQLAlchemy`
- `pydantic`
